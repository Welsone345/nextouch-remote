# Nextouch Пульт

React + TypeScript + Vite + PWA. RS232 и ИК работают только в APK (через Capacitor); в браузере доступен лишь RS232 через Web Serial.

## Веб / PWA
```
npm install
npm run dev
```

## Сборка APK

**Вариант 1 — без установки Android Studio (GitHub Actions).** Залейте папку в репозиторий GitHub → вкладка Actions → «Build APK» → артефакт `nextouch-remote-apk` (файл `app-debug.apk`). Скачайте на телефон и установите (разрешите установку из неизвестных источников).

**Вариант 2 — локально** (нужны Node 20, JDK 17 и Android SDK):
```
npm install
npm run apk
```
APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Скрипт `scripts/setup-android.mjs` сам кладёт плагин, jitpack, зависимость и разрешения в `android/`.

## Разрешения
- `TRANSMIT_IR` — обычное разрешение, выдаётся при установке, отдельного запроса Android не показывает.
- Доступ к USB-адаптеру — Android спрашивает системным диалогом при первом подключении адаптера (приложение запрашивает его само, как только находит адаптер).

## ИК-мастер
Вкладка «Мастер» (режим «ИК»). Для каждой команды 00–FF телефон подряд шлёт кадры сразу 6 типовых вариантов (NEC с адресами 00/04/40/01, Samsung32 07, NEC ext 00FF), так что полный перебор занимает ≈3–4,5 мин, а не 6 × время одного варианта. Нажмите «Доска среагировала» — приложение уточняет код делением пополам (≈5 ответов «да/нет»), затем спрашивает «Удалось подключиться?»: «Да» — вводите название доски, и она сохраняется как профиль, при следующем запуске приложение открывается сразу на ней; «Нет» — перебор продолжается. Варианты типичны для ТВ-пультов, для Nextouch не проверены. Мастер находит одну рабочую команду; остальные кнопки ищите в «Подборе» (протокол и адрес подставятся сами).

## ИК-коды
Коды Nextouch открыто не опубликованы. Три способа:
1. **ИК-подбор** (вкладка при выбранном «ИК»): приложение перебирает NEC-команды 00–FF для заданного адреса, вы смотрите на доску и жмёте «Сработало!» — код сохранится для выбранной кнопки. Если не находится, переберите другие адреса и режим «16-бит адрес (ext)».
2. **Вписать код** во вкладке «Профиль»: `"ir": {"address": 0, "command": 18}`, или `{"ext": true, ...}`, или Pronto `{"pronto": "0000 006D ..."}`, или `{"raw": [9000,4500,...], "freq": 38000}`.
3. **Снять с родного пульта** ИК-приёмником (VS1838B + Arduino/ESP, Flipper и т.п.) и вписать как в п. 2.

Подбор находит только протоколы типа NEC. Если пульт Nextouch использует другой протокол, нужен способ 2 или 3.

## Железо
- **ИК**: нужен телефон со встроенным ИК-излучателем (часть Xiaomi/Redmi/POCO и др.). У iPhone его нет.
- **RS232**: USB-OTG + USB-RS232 адаптер (CH340/FTDI/CP210x/PL2303) + кабель к DB9 доски. Если доска молчит, попробуйте нуль-модемный (перекрёстный) кабель.

## Коды
Протокол Nextouch открыто не опубликован, поэтому профиль «Nextouch» пустой. Заполните его во вкладке «Профиль»:
`hex` — команда RS232, `ir: {address, command}` — NEC-код (38 кГц), а также параметры порта.
Профиль «Allsee 3188» — для проверки линии.
